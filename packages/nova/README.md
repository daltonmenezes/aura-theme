# Aura Theme for Nova

> A dark and aesthetic theme for [Nova](https://nova.app) by Panic.

Part of the [Aura Theme](https://github.com/daltonmenezes/aura-theme) project.

## Variants

- **Aura Theme** — standard version
- **Aura Theme (Soft)** — softer color variant

## Installation

1. Download or clone this repository
2. Double-click `aura-theme.novaextension` to install
3. Go to **Nova → Settings → Themes** and select **Aura Theme**
