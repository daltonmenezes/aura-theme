# Aura Theme for Nova

Port of Aura Dark for [Panic Nova](https://nova.app/).

## Install manually

1. Clone this repository.
2. In Nova, open **Extensions → Library**.
3. Click the gear icon and choose **Install Extension from Folder…**.
4. Select `packages/nova`.
5. Choose **Aura Dark** in **Nova → Settings → Theme**.

## Included themes

- Aura Dark
