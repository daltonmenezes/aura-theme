# Themes available

- Aura Dark
- Aura Dark (Soft Text)
- Aura Soft Dark
- Aura Soft Dark (Soft Text)

# Installation

1. Open Nova.
2. Open **Extensions** > **Activate Project as Extension...**.
3. Select the `Aura Theme.novaextension` folder.
4. Open **Settings** > **Theme**.
5. Search for `Aura` and choose an `Aura` variant.
