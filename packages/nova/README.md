# Themes available

- Aura Dark
- Aura Dark (Soft Text)
- Aura Soft Dark
- Aura Soft Dark (Soft Text)

# Installation

1. Download or clone this repository.
2. Open `packages/nova/Aura.novaextension`.
3. Double-click `Aura.novaextension` to add it to Nova.
4. Open Nova Preferences.
5. Go to the Theme tab.
6. Select one of the Aura variants.

<br/>
Done! ✨ 🎉
