# Installation

1. Open the `Aura.novaextension` folder with Nova.
2. Activate the extension from **Extensions > Activate Project as Extension**.
3. Choose one of the Aura themes from Nova's theme preferences.

# Included themes

- Aura Dark
- Aura Dark Soft Text
- Aura Soft Dark
- Aura Soft Dark Soft Text
