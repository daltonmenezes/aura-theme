# Themes available

- Aura Dark
- Aura Dark (Soft Text)
- Aura Soft Dark
- Aura Soft Dark (Soft Text)

# Installation

1. Download or copy the `Aura.novaextension` bundle.
2. Double-click `Aura.novaextension` to install it in Nova.
3. Open `Nova` > `Settings` > `Theme`.
4. Select your favorite Aura theme variant.
