# Themes available

- Aura Dark
- Aura Dark (Soft Text)
- Aura Soft Dark
- Aura Soft Dark (Soft Text)

# Installation

1. Build or download the `packages/nova/Aura.novaextension` folder.
2. Move `Aura.novaextension` to Nova's extensions folder:
    ```sh
    mkdir -p "$HOME/Library/Application Support/Nova/Extensions"
    cp -R Aura.novaextension "$HOME/Library/Application Support/Nova/Extensions/"
    ```
3. Restart Nova.
4. Open **Nova > Settings > Theme** and choose an Aura theme variant.

{{{ done }}}
