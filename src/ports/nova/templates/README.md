# Installation

1. Download or clone this repository.
2. Open `packages/nova/{{ shortName }}.novaextension`.
3. Double-click `{{ shortName }}.novaextension` to add it to Nova.
4. Open Nova Preferences.
5. Go to the Theme tab.
6. Select one of the {{ shortName }} variants.
